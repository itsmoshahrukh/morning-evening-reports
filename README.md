# Shift Report Builder

Builds the Blue Wall Morning / Evening sales reports and the Harvest weekly report from Transact Cloud POS
"Item Sales Detail – modifier count detailed" exports (.xls or .xlsx).

**Use it:** open the GitHub Pages link, drop in the exports, click **Build reports**, then **Download**.

- Runs entirely in your browser (Python via Pyodide). Sales files are never uploaded.
- Works in current Chrome, Edge, Safari or Firefox. Nothing to install.
- Every report is reconciled against the register totals before it is built.
